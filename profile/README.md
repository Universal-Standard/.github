# Universal Standard

Systems, standards, and open-source tooling for AI orchestration and civic
technology — built for scale, interoperability, and rapid iteration.

## What's here

- **[UniversalStandards/UniversalStandards](https://github.com/UniversalStandards/UniversalStandards)** — canonical engineering standards, manifests, and reusable templates
- **[PROJECT-SWARM](https://github.com/Universal-Standard/PROJECT-SWARM)** / **[SWARM](https://github.com/Universal-Standard/SWARM)** — modular, autonomous multi-agent framework for cooperative AI systems
- **[CAROMAR](https://github.com/Universal-Standard/CAROMAR)** — tooling for forking, copying, and merging repositories across GitHub
- **[ATLANTIS-AI](https://github.com/Universal-Standard/ATLANTIS-AI)** — knowledge curation and predictive-analytics tooling
- **[Universal-Standard-MCP-Server](https://github.com/Universal-Standard/Universal-Standard-MCP-Server)** — MCP server implementation for the org's tooling

## Contributing

Start with [CONTRIBUTING.md](https://github.com/Universal-Standard/.github/blob/main/CONTRIBUTING.md)
and the [Code of Conduct](https://github.com/Universal-Standard/.github/blob/main/CODE_OF_CONDUCT.md).
Cross-project engineering standards live in the `standards/` directory of
[UniversalStandards/UniversalStandards](https://github.com/UniversalStandards/UniversalStandards).
