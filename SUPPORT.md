# Support

This is the organization-wide default support policy for `Universal-Standard`
repositories.

## Before asking for help

- Check the repository's own `README.md` — most setup and usage questions
  are answered there.
- Search closed issues and discussions; your question may already be
  answered.

## Where to get help

- **Bug reports and feature requests**: open an issue using the repository's
  issue templates.
- **Usage questions, design discussion, "how do I…"**: use
  [GitHub Discussions](https://github.com/orgs/Universal-Standard/discussions)
  on the relevant repository if enabled, otherwise open an issue tagged
  `question`.
- **Security vulnerabilities**: do not use issues or discussions — see
  [SECURITY.md](./SECURITY.md).

## Response times

This organization is maintained on a best-effort basis. There is no
guaranteed response SLA for community support requests.

## Commercial / dedicated support

If you require a dedicated support agreement or SLA for a
`Universal-Standard` project, contact **philip.cotton@spurs.agency** to
discuss options.
